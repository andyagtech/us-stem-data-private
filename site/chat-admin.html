Chat analytics moved off the web

This page used to read chat logs from a Lambda Function URL that required no authentication. Anyone who viewed source here could read every visitor's IP address alongside the question they asked. That endpoint has been deleted.

Analytics are now read locally, over IAM, with credentials you already have:

AWS_PROFILE=personal python3 scripts/chat_logs.py --days 30

--anonymise masks addresses when output is going somewhere else, --json gives raw records, --summary gives counts without message bodies.
